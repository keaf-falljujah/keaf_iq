موقع كيف KEAF Coffee House
==========================
index.html  : كل كود الموقع (الصفحات والتصميم والسلة والبحث)
images/     : كل الصور
   products/    : صور الأصناف (أسماؤها في ملف _names.txt)
   categories/  : أيقونات الأقسام في شريط التصفية
   logo.webp, hero-*.webp, pattern.webp, about-art.webp : الشعار وصور الواجهة

مهم: ارفع index.html ومجلد images معاً وبنفس الترتيب، وإلا لن تظهر الصور.
